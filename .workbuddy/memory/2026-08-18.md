
## cloudbase-skills 安装（绕过 GitHub 网络问题）
- 目标：`npx skills add tencentcloudbase/cloudbase-skills -y`
- 问题：github.com:443 连接超时（国内网络），git clone / npx skills 反复失败
- 方案：`curl -sL https://codeload.github.com/tencentcloudbase/cloudbase-skills/tar.gz/refs/heads/main` 下载成功 → 解压 → `npx skills add "<本地路径>" -y` 本地路径安装
- 注意：Git Bash 的 /tmp 与 Windows 路径不同（Node/npx 会解析成 C:/tmp），传参用 `cygpath -w` 转出的绝对路径
- 结果：cloudbase skill 已装到 `%LOCALAPPDATA%\Temp\.agents\skills\cloudbase`（对 Codex agent 可见）
- 教训：codeload.github.com 比 github.com 主站连通性好，可作为国内 GitHub 下载备选
