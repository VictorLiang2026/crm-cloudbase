# 2026-08-22 CRM 列表页优化（5 项修复）

## 问题根因

admin.html 的 `el()` 工具函数只对 `onclick` 做了属性赋值，`oninput`/`onchange` 等走 `setAttribute` → 函数被字符串化 → 闭包变量丢失 → 搜索框和照片上传静默失败。同理 `disabled` 走 `setAttribute('disabled', false)` 仍会禁用按钮 → 分页按钮无效。

## 修复内容

### 1. el 函数修复
- `on*` 属性：检测 `k.indexOf('on')===0 && typeof attrs[k]==='function'` → 改为 `n[k] = attrs[k]`（属性赋值，保留闭包）
- `disabled`：改为 `{ if(attrs[k]) n.disabled = true; }`（只在 truthy 时设置）

### 2. 搜索：回车 + 按钮
- 移除 `oninput:debounce`（自动搜索）
- 改为 `addEventListener('keydown', Enter→搜索)` + 搜索按钮 `onclick`
- 部分匹配在云函数 JS 端实现（`.toLowerCase().includes(kw)`）

### 3. 表格列调整
- 旧列：姓名、电话、阶段、优先级、职业、生日、操作
- 新列：姓名、签单优先级、招募优先级、转介绍优先级、客户经营阶段、本次跟进日期、下次跟进日期、编号、操作

### 4. 排序
- 可排序列：sales_priority、recruitment_priority、referral_priority、latest_followup_date、next_followup_date、Id
- 点击表头切换正序/倒序，`makeSortHeader()` 函数生成带 ▲/▼ 箭头的 th
- 云函数 list 改为：查全部客户 + 全部 followups → JS 端合并/过滤/排序/分页
- null 值始终排末尾（`if(va==null) return 1; if(vb==null) return -1;`）

### 5. 照片上传
- `onchange` 被修复后自动恢复工作（无需额外代码改动）

## 部署变更
- `cloudfunctions/customers/index.js`：LIST_COLS 加 recruitment_priority/referral_priority；list 函数重写
- `admin.html`：el 函数修复 + showList 重写 + makeSortHeader 新增
- `.deploy/customers/index.js`：同步自 cloudfunctions
