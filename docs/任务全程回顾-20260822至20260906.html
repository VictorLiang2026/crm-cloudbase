📌关键经验教训（踩过的坑）

坑沉淀的对策
免费套餐 AI 模型静默忽略图片，解析只有文件名前端本地 OCR（Tesseract.js + pdf.js）兜底，不依赖云端视觉模型
iOS Safari 后台回收标签页，5 分钟超时被绕过最后活动时间持久化 localStorage，重载后仍按真实经过时间判断
CDN/浏览器缓存导致新版页面不显示no-cache meta + 部署后 MD5 核对（URL 带时间戳）+ 无痕窗口验证
admin.html / index.html 双文件内容漂移统一仅用 admin.html，托管首页改指它，删除 index.html
PG 基表加列后视图不自动包含，新字段界面不显示固化 pg-view-rebuild-check 技能：表结构变更后检查并重建依赖视图
同一文件多个 Edit 并行执行，后写覆盖先写（按钮丢失）同一文件的编辑串行执行，不放进同一并行批次
数字直传 appendChild，真实 DOM 抛错整页「加载失败」el() 统一类型兜底；无头测试桩必须严格模拟 DOM（拒收非 Node、innerHTML 清空）
日期 toISOString 按时区回退一天日期算术统一 UTC（T00:00:00Z + setUTCDate）
PowerShell 5.1 按 GBK 读无 BOM 脚本，中文乱码报语法错.ps1 脚本一律存为 UTF-8 带 BOM
提交/推送/部署靠人工记忆，容易漏release.ps1 + sync-check.ps1 制度化，体检全绿才算收尾
